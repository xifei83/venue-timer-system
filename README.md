# 计时计费系统

一个功能强大的多组别计时计费单机软件，用于项目时间管理和费用计算。

## 功能特性

### ⏱️ 核心功能
- **精确计时**：毫秒级精度的计时器
- **灵活控制**：支持开始、暂停、继续、重置
- **实时计费**：根据设定的费率实时计算费用

### 📁 多组别管理（新增）
- **创建组别**：支持创建多个项目组别（如：项目A、项目B、咨询服务等）
- **组别切换**：快速切换不同组别进行独立计时
- **独立费率**：每个组别可设置不同的费率
- **删除组别**：可删除不需要的组别及其关联记录
- **数据隔离**：各组别记录独立，方便查看和管理

### 💰 费率管理
- 可自定义每组别的每小时费率
- 实时显示当前组别的累计费用
- 支持不同项目不同费率

### 📊 统计功能（新增）
- **组别统计**：显示每个组别的总费用、记录数、总时长
- **记录筛选**：自动筛选当前选中组别的记录
- **总览统计**：汇总所有组别的总费用和记录数

### 📋 记录管理
- 自动保存每次计费记录
- 显示组别名称、任务名称、开始时间、时长、费率、费用
- 支持删除单条记录
- 统计总记录数和总费用

### 💾 数据持久化
- 使用浏览器本地存储
- 刷新页面数据不丢失
- 关闭浏览器后数据保留
- 组别和记录数据自动保存

## 使用方法

### 基本操作

1. **选择组别**
   - 点击页面顶部的组别标签选择要使用的组别
   - 可以创建新组别或删除现有组别

2. **设置组别费率**
   - 选中组别后，在组别配置区域修改费率
   - 费率自动保存

3. **开始计时**
   - 输入任务名称（可选）
   - 点击"开始计时"按钮

4. **暂停/继续**
   - 点击"暂停"暂停计时
   - 点击"继续计时"恢复计时

5. **完成并保存**
   - 点击"重置"按钮
   - 系统自动保存本次计费记录到当前组别
   - 计时器归零，可开始新的计时

6. **查看记录**
   - 下方表格显示当前组别的所有记录
   - 顶部统计卡片显示所有组别的汇总信息
   - 点击"删除"按钮可删除单条记录

### 组别管理

1. **创建新组别**
   - 点击"新建组别"按钮
   - 输入组别名称和默认费率
   - 点击确认

2. **切换组别**
   - 直接点击组别标签进行切换
   - 当前组别会高亮显示

3. **修改费率**
   - 选中组别后，在组别配置区域修改费率
   - 费率实时生效

4. **删除组别**
   - 选中要删除的组别
   - 点击"删除组别"按钮
   - 确认后删除组别及其所有记录

### 使用场景

- **项目管理**：为不同项目创建组别，分别计时计费
- **多种服务**：咨询服务、技术支持、设计服务等不同费率
- **团队协作**：不同团队成员或服务类型的独立计费
- **业务分类**：按照客户或业务类型分类管理

支持所有现代浏览器：
- Chrome/Edge (推荐)
- Firefox
- Safari
- Opera

## 开始使用

直接双击 `timer-app.html` 文件，即可在浏览器中打开使用。

## 默认组别

系统初始化时会创建 3 个默认组别：
1. 默认组别（100 元/小时）
2. 项目A（150 元/小时）
3. 咨询服务（200 元/小时）

您可以根据需要修改或删除这些组别。
